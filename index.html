Three steps.

Make haptics for a video in a few minutes.

  1. 1

    Import a video.

    Start Feel Editor. Import a video. Feel Editor keeps a reference to the file. It does not copy the video.

  2. 2

    Pair your phone.

    Put the Mac and the phone on the same network. Open the phone app. Scan the QR code in Feel Editor.

  3. 3

    Edit and feel.

    Edit the timeline. The phone plays the haptics in sync with the video. Then export.

FormatFilesPlatformUse
AHAP<project>.ahapiOSPlay the pattern with Core Haptics. No video sync.
JSON<project>.jsoniOS, AndroidOpen the file in Feel for iPhone or Feel for Android.
SwiftFeelHapticVideoSync.swiftiOS 16 or laterSync haptics with AVPlayer.
KotlinFeelHapticVideoSync.ktAndroid 8.0 or laterSync haptics with a Media3 player.
// Add FeelHapticVideoSync.swift and <project>.ahap to your target.
let player = AVPlayer(url: videoURL)
let haptics = try HapticVideoSync(player: player, resource: "<project>")
player.play()

// Keep a strong reference to `haptics` while the video plays.
// Copy FeelHapticVideoSync.kt to your source folder.
// Copy <project>.json to app/src/main/assets/.
val player = ExoPlayer.Builder(this).build()
val haptics = HapticVideoSync.fromAsset(this, player, "<project>.json")

player.setMediaItem(MediaItem.fromUri(videoUri))
player.prepare()
player.play()

// When you close the screen:
haptics.release()
player.release()

Questions.

Do I need a Mac?

No. Open the phone app, select a video, and feel the haptics. You need the Mac to edit the haptics.

What do I need for live preview?

Put the Mac and the phone on the same network. Scan the QR code in Feel Editor with the phone app.

Can I connect more than one phone?

Yes. Many phones can connect at the same time. This was tested.

What happens if my export folder has old files?

Export replaces files that have the same name. Export to an empty folder if you must keep the old files.

When does export stop?

Export stops if the project has no events, or if an event has an invalid number. Export shows a warning, and continues, if an event is outside the video, an event has zero intensity, or the project has no video.

Why are the Android haptics weak or off?

The Media vibration setting on the device controls the strength. If it is off, the haptics do not operate. On a Pixel, find it in Settings > Sound & vibration > Vibration & haptics.

Why do the Android haptics stop for a moment?

A system vibration, such as a touch vibration, can stop the haptics for a maximum of 1.5 seconds. The haptics then start again automatically.

Can I build the apps myself?

Yes. The source is on GitHub. Apple apps need macOS 14, Xcode, and XcodeGen. The Android app needs JDK 17 and the Android SDK. See the build guide.
